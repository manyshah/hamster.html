# آکادمی همستر

پروژه HTML/CSS/JavaScript چندصفحه‌ای، فارسی و RTL برای اپ آموزش نگهداری همستر.

## اجرا روی GitHub Pages
فایل‌ها را در ریشه ریپازیتوری قرار دهید و GitHub Pages را روی Branch اصلی فعال کنید.

## ساختار
- `index.html`: صفحه اصلی
- `style.css`: طراحی، تم، ریسپانسیو
- `script.js`: داده‌ها، ناوبری، آزمون، علاقه‌مندی‌ها، پروفایل و تم
- `pages/`: صفحات داخلی
- `assets/`: تصاویر و آیکون‌ها

## آمادگی برای Flutter
ساختار UI به صورت کامپوننتی طراحی شده و می‌تواند به Widgetهایی مثل `AppShell`, `CourseCard`, `CategoryCard`, `QuizWidget`, `ProfileHeader`, `SettingsTile` تبدیل شود.
