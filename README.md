# آموزش همستر کمبت
پروژه HTML/CSS/JS فارسی، RTL، موبایل‌فرست و آماده GitHub Pages.

## ساختار
- index.html صفحه اول اپ‌مانند
- pages/categories.html دسته‌بندی آموزش‌ها
- pages/lesson.html صفحه درس پویا
- pages/quiz.html آزمون
- pages/about.html درباره ما
- pages/apps.html سایر برنامه‌ها
- pages/rate.html ثبت نظر در مارکت

این پروژه غیررسمی و فقط آموزشی است.
